# Lucas Guilherme Nasciben

**AI Builder | Produtos com IA, automação e análise de dados**

Meu foco é transformar problemas concretos em ferramentas utilizáveis, conectando contexto de negócio, interfaces, APIs e validação.

Uso principalmente Codex e Kiro no desenvolvimento dos meus projetos. A construção é apresentada com evidências, decisões e limites — incluindo a diferença entre IA aplicada ao produto e IA utilizada no desenvolvimento.

## Projetos em destaque

| Projeto | O que construí | Competência demonstrada |
|---|---|---|
| [**DiárioPro**](https://github.com/lukeg5613-source/diariopro-portfolio) | Fluxo de planejamento de aulas com IA, referências curriculares e DOCX editável | IA aplicada a uma tarefa real e entrega de ponta a ponta |
| [**PokerFieldAnalyzer**](https://github.com/lukeg5613-source/pokerfieldanalyzer-portfolio) | Plataforma de estatísticas, revisão e índices incrementais | Qualidade de dados, análise e integração de componentes |
| [**Papagaio Promoções / PromoBot**](https://github.com/lukeg5613-source/papagaio-promocoes-portfolio) | Automação de curadoria, deduplicação e revisão de ofertas | Processos operacionais, integração e tratamento de ambiguidades |

**Tecnologias presentes nos projetos:** Python, FastAPI, SQLite, SQLAlchemy, JavaScript, integração com APIs de IA e automação.

Os estudos de caso públicos contêm documentação e capturas selecionadas. Código-fonte e dados operacionais permanecem privados.
